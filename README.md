# Sync DJ Tools Suite

Uma suíte de ferramentas para DJs que usam o ecossistema **Engine DJ** (Denon DJ / Numark) e **VirtualDJ**. O aplicativo reúne sincronização de biblioteca, recuperação de arquivos, gerenciamento de metadados, playlists e histórico em uma interface única.

## Funcionalidades

### Mirror Sync — pasta para Engine DJ

Espelha dua biblioteca de músicas no Engine DJ. O Engine DJ não atualiza a bibliteca de musicas quando musicas são adicionadas nas diversas pastas. Essa ferramenta faz um comparativo do banco de dados com sua pasta de musicas do computador e atualiza a biblioteca.

### Sync VDJ — Engine DJ e VirtualDJ

- Exporta playlists do Engine DJ para o Virtual DJ, salvando em arquivos .vdjfolder.
- Importa Playlists do Virtual DJ para o Engine DJ

### Importar Hotcues de MP3

Importa pontos de cue armazenados nas tags de arquivos MP3 por ferramentas como Mixed In Key e Serato e salva no Engine DJ.

### Reencontrar músicas perdidas

Encontra no computador faixas que aparecem como ausentes no Engine DJ.

### Descobrir músicas e atualizar tags

Identifica arquivos de áudio com reconhecimento Shazam e melhora seus metadados.

### Ferramentas Engine DJ

- Importar playlist do dispositivo: Importa playlists criadas e/ou atualizadas diretamente no equipamento e importa para o banco de dados do Engine DJ.

- Histórico de eventos: Com base nos históricos de eventos, gera arquivo com imagens para divulgação nas redes sociais. (Em desenvolvimento)

- Smart Playlist: Cria uma playlist com base em uma musica escolhida, fazendo ajustes do BPM, KEY e Energia.
